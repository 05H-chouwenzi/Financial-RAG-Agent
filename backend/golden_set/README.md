# Golden Set 标注规范

目标：**150 条**高质量标注数据，用于检索质量与生成质量评估。

## 字段说明（golden_set.csv）

| 字段 | 说明 |
|---|---|
| id | 唯一编号，如 G0001 |
| type | 问题类型（见下表） |
| question | 问题原文 |
| answer | 标准答案（事实性，可附引用） |
| doc_ids | 答案来源文档标识（如 `000001_2023年报`） |
| page | 页码（可选） |
| evidence | 原文证据片段（**必须**，用于检索命中判定） |
| note | 备注 / 易错点 |

## 问题类型

| type | 说明 | 示例 |
|---|---|---|
| fact | 事实抽取 | "2023 年公司营业收入是多少？" |
| table | 表格问答 | "前十大股东中持股比例最高的是谁？" |
| compare | 跨年度/跨项对比 | "2022 vs 2023 毛利率变化？" |
| calc | 指标计算 | "2023 年 ROE 是多少？" |
| multi_doc | 多文档/多公司 | "对比 A 和 B 公司的资产负债率" |
| reject | 拒答（知识库外） | "公司 2025 年战略规划是什么？" |

## 构造流程

1. 从年报/公告人工出题（保证真实）
2. LLM 辅助生成草稿 → 人工逐条校验（evidence 必须真实存在）
3. 按类型分布：fact 40 / table 30 / compare 25 / calc 20 / multi_doc 20 / reject 15
